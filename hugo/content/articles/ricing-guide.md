If you know a little bit about Linux and you've used the command line
and package managers before but haven't really gotten into customizing
your system, then this article might be for you.

Firstly, on the choice of distribution, I'm currently running Ubuntu 24
and I distro-hopped to Arch and Fedora a bunch before settling on it
and, to be honest, I'm yet to find a truly meaningful difference between
distros. Use whatever works for you. To check your distro, you can run:

```bash
cat /etc/os-release

```

This setup is quite basic and minimal.

I've been using Linux for about two years now.
But only this summer I finally got into window managers and customization.
I tried using i3wm a year ago but it really isn't intended to be used out of the
box and I didn't have enough time to tinker with it so I gave up on it.
This time, however, I spent quite a bit of time customizing my setup. But I'm
lazy and I don't really need that much from my system anyway, so you might consider
my setup to be very minimal. Nevertheless, I hope you find this useful.
